# Tic Tac Toe Project Template

This is a template for creating a basic Tic Tac Toe game in java.

## Instructions
- Implement a fully functional game of Tic Tac Toe in the terminal.
- Fully address all TODO comments.
- Ensure that you show your work thoroughly across multiple commits.

For additional instructions, see the [last section of Chapter 1](https://docs.google.com/document/d/1du1wdfCDV_ItNRmlIkbZu90ODlOhq23gx_gZdmTtot0/edit?tab=t.ekctm4xf9ufh#heading=h.7x2kyy6if8dr).
